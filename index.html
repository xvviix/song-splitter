How XVVIIX works

Everything happens inside this browser tab. Your song is never uploaded, and no server is involved at any point.

  1. DecodeYour file is decoded to raw audio with the Web Audio API.
  2. AnalyseA short-time Fourier transform splits the track into a time-frequency spectrum.
  3. SeparateHarmonic/percussive median filtering isolates sustained tones from transients, while stereo centre extraction pulls out the vocal. Frequency weighting then splits bass from the rest.
  4. RebuildEach stem is resynthesised and encoded to WAV, entirely on your device.

This is classic signal processing rather than an AI model, so it stays fast and fully offline. Results are good for remixing, practice and karaoke, but less surgical than a heavyweight server-side model.

Unlock Best quality

Best quality runs the real Demucs AI model. It needs a one-time setup on your own computer - after that it is unlimited, private and works offline. Your audio is never uploaded anywhere. Use the one-click installer, or set it up by hand from the repository.

1
Download the installerOne file. The engine is built into it - nothing else to download.
⊞ Windows⌘ macOS / Linux
2
Run itPut it in its own folder, then double-click install-xvviix.bat. A black window opens and does the rest.
3
Wait for the installIf you already have PyTorch 2.0+ installed, the installer reuses it and downloads only a few MB. Otherwise it fetches the AI engine: about 250 MB on a normal computer, or 2.5 GB if you have an NVIDIA graphics card (the CUDA libraries are large, but make it ~10x faster). Later runs start instantly.
4
Come back hereWhen the window says READY, this page detects it automatically and Best quality unlocks.

Prefer to see exactly what you are running? Clone the repository and start the engine yourself. Nothing is downloaded from this page, and you can read engine/xvviix_engine.py before running it - it is plain Python with no third-party imports.






You need: Git and Python 3.9+. The pip install step is the big one - it pulls PyTorch and Demucs. If you already have PyTorch 2.0+ in that environment, only Demucs is fetched.



When the terminal prints READY, come back to this tab. The page checks 127.0.0.1:8765 every few seconds and unlocks Best quality on its own. To stop the engine, press Ctrl+C in the terminal.
